# ATLAS DISTRICT 电影级巨构 P0 验收记录

## 本阶段目标

只处理构图、镜头、巨构灰模比例与英雄净空，不提前加入轨道、月亮、云雾和装饰细节。

## 已实现

- 建立镜头：`[-270, 155, -305] → [0, 28, 45]`，垂直 FOV `46°`。
- 英雄镜头：`[-65, 7, -205] → [0, 52, 9]`，垂直 FOV `40°`；实算仰角约 `11.4°`。
- 巨构灰模：`64 × 96 × 18`，包含厚重门柱、双层横梁、深凹入口与主要斜撑。
- 巨构高度约为核心普通建筑中位高度的 `6.33` 倍。
- 以渲染层派生英雄净空，不修改 CitySeed、建筑 ID 或 StableCity 签名。
- Hero 主题附件改为依附新巨构锚点；投影阴影范围覆盖 96 高主门但不扩大到整座城市。

## 自动验证

- 英雄相机高度处于 `3–10`，仰角处于 `8–15°`。
- 基准画幅中巨门占画面高度 `55%–75%`。
- `0.5 / 1.5 / 2.5` 三种画幅下巨构包围盒不裁切。
- 净空结果确定、可见建筑不与巨构包络重叠，StableCity 签名保持不变。
- 完整 `pnpm validate` 与 `git diff --check` 通过后才允许提交。

## 浏览器观察

- 真实页面可在“城市总览 / 巨构特写”间切换；英雄镜头明显由高位俯视变为低位仰视，主门成为单一大形。
- 当前内置浏览器偶尔同时显示 WebGL 降级占位与实时指标，因此本阶段只把页面观察视为构图佐证，不将其伪报为完整 GPU 视觉验收。
